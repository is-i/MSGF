# Iteration 2 — Incorporación de becas-crédito

Esta iteración incorpora un nuevo requerimiento al sistema
de información de la Fundación MSG.

## Nuevo requerimiento

La Fundación otorgará becas-crédito para estudios,
financiadas mediante aportes recibidos anualmente.

Consultar la [descripción completa del requerimiento](becaCr%C3%A9dito%20description.md).

## Modelos actualizados

Los siguientes modelos fueron modificados para incorporar
el nuevo requerimiento:

- Diagrama de casos de uso.
- Diagrama de clases.
- Diagrama de máquinas de estado.
- Diagrama de clases límite y control.
